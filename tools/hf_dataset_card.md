# AHRQ Elixhauser Comorbidity Software Refined v2027.1: ICD-10-CM mapping

> **Correction notice.** Earlier versions of this dataset were labelled v2025.1. Their `van_walraven_mortality_weight` column did **not** contain AHRQ's index weights and must not be used. They also described the package as "CDC-reviewed", which was inaccurate. This release replaces those files with AHRQ v2027.1 content. If you used the old weight column, re-run with the weights below or with the `elixhauser-ahrq` package {PACKAGE_VERSION}. See [Advisory EOCS-ELX-2026-01](https://github.com/fopelka-EOCS/elixhauser-ahrq/blob/main/docs/ADVISORY-EOCS-ELX-2026-01.md).

This dataset is a machine-readable copy of AHRQ HCUP's **Elixhauser Comorbidity Software Refined for ICD-10-CM, v2027.1** (FY2027; valid for ICD-10-CM codes from October 2015 through September 2027). It contains:
- the mapping from diagnosis codes to comorbidity measures;
- AHRQ's in-hospital mortality and 30-day readmission index weights;
- AHRQ's present-on-admission (POA) exempt-code lists.

It was generated by `tools/build_hf_dataset.py` in [elixhauser-ahrq](https://github.com/fopelka-EOCS/elixhauser-ahrq) from AHRQ's reference workbook and SAS programs, and it is checked code by code against them.

## Files

| File | Contents |
|---|---|
| `elixhauser_icd10_mapping.csv` | 4,573 codes. Each has its description and a 0/1 flag for 39 mapping columns, exactly as in AHRQ's `DX_to_Comorb_Mapping` sheet. Cerebrovascular disease appears as two mapping columns, `CBVD_POA` and `CBVD_SQLA`, which AHRQ combines into the single measure `CBVD`. |
| `comorbidity_measures.csv` | The 38 measures, with AHRQ's description, whether POA is required, and AHRQ's mortality and readmission index weights (from `CMR_Index_Program_v2027-1.sas`). |
| `poa_exempt_codes.csv` | AHRQ's POA-exempt codes for each ICD-10-CM version, 33 (FY2016) to 44 (FY2027). |

## Important: a code lookup is not the AHRQ algorithm

Taking the maximum of these flags over a patient's codes does **not** reproduce AHRQ's measures. AHRQ's software:
- maps **secondary diagnoses only**; the principal diagnosis is excluded;
- counts the 18 POA-dependent measures only when POA is `Y` or `W`, or when the code is exempt for the discharge's ICD-10-CM version;
- applies the cerebrovascular "not present on admission" rule;
- applies the hierarchy exclusions.

To get AHRQ-faithful results, use AHRQ's SAS software or the `elixhauser-ahrq` package.

## Changes in v2027.1 from v2026.1 (AHRQ change log)

- **8 codes added:** C7831, C7832, C7983 (CANCER_METS); D6911, D6919 (COAG); K740A, K7683 (LIVER_MLD); Z6818 (WGHTLOSS).
- **2 codes removed from DEMENTIA:** F0670 and F0671.
- **Rename:** `DRUG_ABUSE` becomes `DRUG`.
- **Relabel:** ALCOHOL becomes "Alcohol-related disorders".
